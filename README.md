# Comfort Menu

Any menu, in your format, at your pace.

Comfort Menu is a prototype built at Hack for Accessibility 2026. It turns a restaurant menu into the format a person chooses, then hands the finished order to the crew as a clear card they can read or hear.

## What it does

- **Four formats:** Listen (the page reads aloud), Large print, Pictures (one question at a time), and Quiet (no sound, show the order on screen).
- **Ask the menu:** Type a question such as "chicken under $6 with no milk" instead of scrolling the whole menu.
- **Order card:** Review the order, add a note, then play it aloud or show it to the crew.
- **Crew view:** The order in very large type, quick replies, and a box where the crew can type back.
- **Captions:** Everything the page says aloud also appears as text.
- **Saved choice:** The format is remembered on the device for next time.

## Run it

Open `index.html` in a browser. There is nothing to install and no server or API key.

Reading aloud uses the browser's built-in speech. Voice input works best in Chrome and needs an internet connection.

## Accessibility

- Works with a keyboard alone, with a visible focus outline and a skip link.
- Uses real buttons, labels, and headings so screen readers can navigate it.
- Text contrast is above 4.5:1 in every format, in light and dark themes.
- Uses the Atkinson Hyperlegible typeface, designed for low-vision readers.
- No autoplay, flashing, or unexpected motion.

Still to do: testing with screen-reader users and other community members, and fixing what they find.

## Sample data

The menu is a made-up restaurant. Allergen details are sample data and must not be relied on. A real version would use the restaurant's official menu and allergen data.
